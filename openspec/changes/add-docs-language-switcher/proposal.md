# Proposal

## Why

Документация на `openspec.dev/docs` доступна только на английском. Пилот позволит проверить переключение языка на странице установки, не дожидаясь полного перевода.

## What Changes

- На странице установки можно будет переключаться между английской и русской версиями: `/docs/installation` ↔ `/docs/ru/installation`.
- Существующие английские адреса сохранятся. На страницах без перевода переход на русский не предлагается.
- Полный перевод, отдельный русскоязычный поиск и изменения главной `openspec.dev` не входят в пилот.

## Capabilities

### New Capabilities

- `docs-language-switching`: публикация языковых версий документации и переход между переводами одной страницы.

### Modified Capabilities

## Impact

- `docs-lab/`: исходник русского перевода страницы установки.
- `website/`: публикация перевода при статической сборке и переключатель в документации.
- Контекст: [обсуждение многоязычности сайта #1584](https://github.com/Fission-AI/OpenSpec/discussions/1584).
