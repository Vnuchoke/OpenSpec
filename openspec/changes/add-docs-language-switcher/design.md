# Design

## Context

`website/docs.sync.config.mjs` определяет, какие страницы из `docs-lab/` генерирует `website/scripts/sync-docs.mjs`. Страницы рендерятся одним Next.js-маршрутом `website/app/docs/[[...slug]]/page.tsx` через Fumadocs. Текущий Cloudflare Worker уже проксирует `/docs/*`.

## Goals / Non-Goals

- Пилот: русский перевод установки, двустороннее переключение и прямой статический URL.
- Не менять английские URL, главную `openspec.dev`, язык оболочки сайта или настройки поиска. Не добавлять зависимости, сервер, автоопределение языка и хранение предпочтений.

## Decisions

1. **Опубликовать перевод тем же конвейером.** Добавить `docs-lab/ru/start/installation.md` и явную запись перевода для английского slug `installation` в `website/docs.sync.config.mjs`. Из этой записи получить slug `ru/installation`, язык фрагмента страницы и адреса пары переводов. Передавать их через стандартный Fumadocs frontmatter, расширив схему `website/source.config.ts`. Использовать существующий catch-all и `generateStaticParams`, не дублировать страницу и не вводить прокси Fumadocs/Next.js для согласования языка.
2. **Переключать через обычную ссылку рядом с действиями статьи.** Рендерить её только у пары, названия `Русский` и `English` выводить с `lang` и `hrefLang`. Пометить русский контейнер статьи `lang="ru"`, оставив английскую оболочку без изменений. Русский URL доступен напрямую; существующее меню на английском, поиск и маршруты выдачи Markdown продолжают работать на общей коллекции без отдельного русского индекса.
3. **Использовать явные соответствия для ссылок и выходных файлов.** В русском Markdown ссылаться на опубликованные английские исходники относительными путями: существующий индекс `routeBySource` преобразует их в английские URL. При переносе заголовков перевести и проверить локальные якоря. Выходные файлы регистрировать в существующем `written`; не вводить отдельных правил чистки. Для локальной файловой системы использовать `node:path`, а для URL и путей Git — POSIX-представление.

## Risks / Trade-offs

- Русское содержимое будет доступно, но оболочка и общий поиск не локализуются. Пилот проверяет переключение, а не качество поиска на русском.
- Перевод может разойтись с исходником: при первом добавлении сверить команды, ссылки и требования к версиям с `docs-lab/start/installation.md`. Обновить `website/README.md`, чтобы автор видел актуальный источник и способ добавления перевода.
- На предпросмотре проверить прямой запрос и обновление русского URL: локальная статическая сборка не доказывает корректность публикации Cloudflare. Для отката достаточно убрать запись перевода и его источник; английский маршрут не переносится.
