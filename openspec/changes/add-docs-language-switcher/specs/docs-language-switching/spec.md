# Spec Delta

## Purpose

Читатели могут открывать доступные переводы документации и переключать язык, не теряя страницу, которую читают.

## ADDED Requirements

### Requirement: Переключение между переводами одной страницы

На переведённой странице документации сайт SHALL предлагать доступную с клавиатуры ссылку на ту же страницу на другом языке и обозначать язык перевода его собственным названием.

#### Scenario: Переход с английской страницы на русскую

- **WHEN** читатель выбирает «Русский» на `/docs/installation`
- **THEN** открывается `/docs/ru/installation` с русским заголовком и текстом инструкции по установке
- **AND** основной текст страницы помечен как русскоязычный для вспомогательных технологий

#### Scenario: Переход обратно на английскую страницу

- **WHEN** читатель открывает `/docs/ru/installation` по прямой ссылке и выбирает «English»
- **THEN** открывается `/docs/installation` с английской инструкцией по установке

### Requirement: Навигация при неполном переводе

Сайт SHALL сохранять существующие английские адреса и предлагать переключение только для опубликованных переводов. Ссылки из перевода на ещё не переведённые страницы документации SHALL вести на опубликованный английский оригинал.

#### Scenario: Страница настройки пока не переведена

- **WHEN** читатель открывает `/docs/setup`
- **THEN** открывается английская страница настройки без ссылки переключения на русский

#### Scenario: Переход из русской инструкции на страницу настройки

- **WHEN** читатель переходит по ссылке на настройку проекта из `/docs/ru/installation`
- **THEN** открывается `/docs/setup`, а не несуществующий русский адрес

### Requirement: Публикация русской страницы в статической сборке

Опубликованный перевод SHALL открываться по прямому URL из статической сборки независимо от операционной системы, на которой она подготовлена.

#### Scenario: Публикация из рабочей копии Windows

- **WHEN** документация собирается из рабочей копии на Windows
- **THEN** `/docs/ru/installation` содержит русскую инструкцию по установке и ссылку обратно на `/docs/installation`, как и сборка на Linux
